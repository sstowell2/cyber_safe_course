
# Cyber Safe at Home
### Cybersecurity Awareness & Education Project

A free, beginner-friendly cybersecurity course designed to help everyday computer users recognize cyber threats, protect personal information, and develop safer online habits.

## Live Website

[Launch Cyber Safe at Home](https://sstowell2.github.io/cyber_safe_course/)

## Project Overview

Cyber Safe at Home is an interactive cybersecurity education website designed to make security concepts understandable for people without a technical background.

The course uses plain-language explanations, real-world examples, hands-on activities, and knowledge assessments to reinforce good cybersecurity practices.

## Key Features

- Seven beginner-friendly cybersecurity lessons
- Phishing awareness and scam recognition
- Password management and safer authentication
- VPN and public Wi-Fi security education
- Windows security and software update guidance
- Interactive learning exercises and quizzes
- Browser-based lesson progress tracking

## Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub
- GitHub Pages

## Cybersecurity Concepts

The course introduces important security principles, including:

- Social engineering and phishing prevention
- Password security and multifactor authentication
- Safe browsing and network security
- Personal data protection
- Security awareness and risk reduction

## Project Purpose

The goal of this project is to make cybersecurity education accessible to everyday computer users.

It also demonstrates the practical application of cybersecurity awareness, technical communication, web development, and online education.
